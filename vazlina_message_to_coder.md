## Color Palette (Final — Option F)

| Token | Hex | Usage |
|-------|-----|-------|
| Primary Dark | `#1C1C1E` Charcoal | Buttons, nav, announcement bar, banners, borders |
| Accent | `#D4A5A5` Rose Gold | Stars, section labels, badges, CTA highlights, quotes |
| Background | `#FAF5F5` Warm pink-white | Page bg, cards |
| Border | `#E8E0E0` | Card borders, dividers |
| Text Primary | `#1A1A1A` | Headlines, body |
| Text Muted | `#6B6B6B` | Descriptions |

**Rules:** No blue, no green, no yellow stars. Rose Gold everywhere the prompt says "gold" or "accent."

- **Body:** Inter

## The Rules
1. **Follow the prompt section by section.** Do not skip any section.
2. **Missing sections** in the current code (How It Works, Timeline, Comparison, Guarantee, COD Process, cross-sell, mobile sticky bar) — **build them all.**
3. **Mobile-first + desktop-perfect.** 70% of traffic is mobile. Every section must look native and premium on a 375px screen. Desktop must feel equally polished.
4. **Animations:** Section fade-in on scroll, card hover lift, button scale on press, smooth announcement transitions.
5. **No shortcuts:** Do not simplify badges, do not skip hover states, do not merge sections.
